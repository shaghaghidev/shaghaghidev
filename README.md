## 04 / DESIGN MINDSET

I care about websites that are:

**Clear** — the interface should communicate quickly.  
**Useful** — visual design should support the user.  
**Responsive** — the experience should survive different screens.  
**Intentional** — details shouldn't exist just because they can.  
**Honest** — the portfolio should represent the actual level of the work.

I prefer a strong visual idea over adding more sections, effects or unnecessary UI.
